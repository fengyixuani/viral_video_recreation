生图 Prompt 指南（Seedream 4.0 / 5.0）

## 核心结构

```
主体 + 动作/姿态 + 环境/场景 + 风格 + 构图 + 光影/色彩 + 输出目标
```

用**简洁连贯的自然语言**，不要堆叠华丽词汇——Seedream 上简洁精确优于冗长辞藻。

必填三要素：主体、行为、环境。有美学要求再补风格、色彩、光影、构图。

重要原则：

1. 越重要的信息越前置。特别是特殊关键词：人物保持不变；真人写实风格

* 多说要什么，少说不要什么！尽量用正向描述词说清楚要什么。比如，`真人写实风格而非漫画`应该修改为：`真人写实风格`

## 各要素写法

- 主体：具体到材质、数量、状态（"哑光金属无线台灯" 优于 "一盏灯"）
- 场景：明确环境与背景元素
- 构图：广角 / 中景 / 特写 / 俯拍 / 居中主视觉 / 竖版；需要留白就直接说"左侧留干净空间放文字"
- 风格：只指定**一种**风格关键词，混搭会不一致
- 光影：给方向 + 性质（"左上方聚光斜射，柔和长阴影"）
- 分辨率：写明确值（"4K"、`size=2048x2048`），不要写 "high resolution"
- 用途：有明确落地场景时写出来（海报 / 电商主图 / 社媒帖 / 教学插图）

## 任务类型差异

### 文生图

细节丰富的图可用详细分层描述精准控制（如"上层左边…中层…下层…"）。
知识类图表（公式、图示、教学插图）要用准确专业术语，并写清可视化形式与版式。

### 参考图生图

提示词必须写清两件事：

1. **参考对象**：从参考图里要保留什么（人物形象 / 产品材质 / 视觉风格）
2. **生成画面**：要生成的内容、场景、位置、尺寸

参考图使用：

- 输入质量决定输出质量，用高清、光线好的图
- 按意图选图：风格迁移传风格图；保人物一致传清晰正面照
- 从 1-3 张起步，逐步加；最多 14 张
- 参考图定视觉方向，prompt 定具体操作

### 图片编辑

- 指令简洁明确，说清"改哪个对象 + 做什么操作"
- **避免模糊代词**（"它"、"这个"）
- 希望其余不变就显式强调"除…外保持不变"
- 复杂画面难以用文字定位时，用箭头/线框/涂鸦在图上标出编辑区域
- 编辑必须通过 `image_urls` 传原图，否则模型会从零生成

## 图内文字渲染（4.5+）

- 要渲染的文字用**双引号**包裹：`"SUMMER SALE 50% OFF"`
- 指定位置："文字居中置于顶部"
- 3-5 个词最可靠，过长易出错
- 指定字体风格："粗体无衬线"、"优雅手写体"
- 输出 2K/4K，给文字更多像素

## 长度与版本

- 4.0 / 4.5：精炼，2-4 句覆盖主体、风格、关键细节
- 5.0 Lite：可写更长更详细，深度思考能力受益于丰富指令；复杂构图要描述元素间的**逻辑关系**，而非只罗列视觉元素

## 常见错误

- 只说"不要什么"而不说"要什么" → 改为正向描述
- 模糊分辨率描述 → 给明确数值
- 编辑不传参考图 → 变成从零生成
- 多种风格混搭 → 风格不一致
- 纯创意内容开启 `web_search` → 只增成本延迟，无收益
